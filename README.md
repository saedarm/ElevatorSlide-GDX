# Elevators & Laundry Chutes

A 3D race to the roof of a ten-floor apartment tower, built with libGDX for Android (tuned for the Galaxy S23) with a small desktop launcher for testing.

## Rules

- 100 squares spiral up the tower, ten per floor. Square 34 sits directly above 24, 14 and 4.
- Each turn, pick a pace:
  - **Take the stairs**: move 3–6 (a d4 + 2). Steady.
  - **Hustle**: move 1–8 (a d8). Risky.
  - Both average 4.5 squares a turn. The buttons show your exact chance of landing on an elevator or a chute, so the choice is about risk, not speed.
- **Brass shafts** are elevators. Land on the bottom and ride up.
- **Coral tubes** are laundry chutes. Land on the top and slide down.
- **Blue tiles** are mailboxes, two per floor. Land on one to draw a card. Falling down a chute also gets you a card.
- Hold up to 3 cards and play one per turn, before you roll.
- Every 5 rounds a **building event** hits the whole tower.
- Land on exactly 100 to win. Overshoot and you bounce back by the extra.
- 2–4 tenants, any mix of human and CPU. CPU tenants pick the better pace and try each card in a few simulated futures before playing it.

### Cards

The deck is 55% handy, 33% chaos and 12% insane cards.

| Card | Tier | What it does |
| --- | --- | --- |
| Spare Key | Handy, automatic | After you roll, move 1 more or 1 less. You get a prompt showing where each option ends. |
| Doorman Tip | Handy | Your next elevator goes one extra floor. |
| Laundry Bag | Handy, automatic | Your next chute only drops you halfway. |
| Grippy Socks | Handy, automatic | Your next chute, you catch the edge and stay put. Rare. |
| Take the Freight | Handy | Instead of rolling, go straight up one floor. |
| Fire Extinguisher | Handy, automatic | Blocks the next fire, bomb, piano, flood or blast. |
| Sublet | Handy | Swap places with a tenant within one floor of you. |
| Noise Complaint | Handy | That tenant has to take the stairs next turn. |
| Package Theft | Handy | Steal a random card. |
| Cherry Bomb | Chaos | Blows a hole in their square for 3 rounds. They fall a floor, and so does anyone who lands there. |
| Grease Fire | Chaos | Their floor burns for 2 rounds. End a turn there and you drop a floor. |
| Piano Delivery | Chaos | A piano falls down their column and everyone stacked in it drops a floor, you included. |
| Snapped Cable | Chaos | Elevators are broken for 2 rounds; anyone at a shaft top drops to the bottom. |
| Water Tower Burst | Chaos | Everyone on floors 9–10 is washed down a floor. |
| Microwave Incident | Chaos | Everyone else on your floor is knocked back 1–3. |
| Raccoon Infestation | Insane | The chute ahead of you flings people up instead of down for 2 rounds. |
| Alien Abduction | Insane | Instead of rolling, get beamed to a random square on floors 8–10. |
| Earthquake | Insane | Everyone shakes 1–6 squares up or down. |
| Time Warp | Insane | Everyone goes back to where they were a round ago. |
| Bad Wi-Fi | Insane | Everyone else loses their next turn. |

### Building events (every 5 rounds)

| Event | What it does |
| --- | --- |
| Fire Drill | Everyone on floors 9–10 goes down a floor. |
| Power Outage | Elevators are out for one round. |
| Express Hour | Every elevator goes one extra floor this round. |
| Wet Floor | The stairs get slippery and move 2–7 this round. |
| Laundry Pileup | One chute is clogged and only drops you halfway. |
| Rent Day | The tenant lowest in the building gets a free card. |

In 3,000 simulated four-player games with cards on, a game takes about 18 rounds (cards add about 1.5). The tenant leading at round 10 wins 37% of the time and the tenant in last wins 16%, so falling behind is survivable without leading being a curse.

## Menus, settings and sound

The game opens on a title screen (Play, How to Play, Settings, Quit) with the tower turning behind it. How to Play is six pages with pictures from real games. During a game, the **II** button top right pauses everything and opens Resume, How to Play, Settings and Quit to Menu. On the phone, Back works from the inside out: card panel, then How to Play or Settings, then the pause menu.

Settings are saved on the device:

| Setting | Default |
| --- | --- |
| Music volume | 60% |
| Sound effects volume | 80% |
| Vibration (elevators, chutes, big hits) | On |
| Camera follows the action | On |
| Fast animations (about 1.8x) | Off |

All audio is generated by `tools/make_audio.py`: a 37-second elevator-bossa loop (electric piano, vibraphone, bass, shaker and rim, in C major at 104 bpm) and 35 sound effects, about 700 KB in total. To change a sound, edit the script and run `python3 tools/make_audio.py` (needs numpy, scipy and ffmpeg). Or drop a recorded `.ogg` into `assets/audio/` with the same name.

## Project layout

```
core/      all game code (shared)
android/   Android launcher, manifest, icon
lwjgl3/    desktop launcher for quick testing
assets/    fonts (Bungee, Bricolage Grotesque, both SIL OFL), audio, How to Play pictures
tools/     make_audio.py, which generates the music and sound effects
```

Everything 3D is built in code with `ModelBuilder`. There are no model files and no skin file.

| File | What it does |
| --- | --- |
| `Board.java` | The fixed board: elevator, chute and mailbox tables, bounce-back. |
| `Card.java` | The deck: every card's tier, text and draw weight. |
| `Engine.java` | All the rules as plain Java: turns, cards, events, timed effects, odds, CPU decisions. It never draws anything, so it can simulate thousands of games headless. |
| `Beat.java` | One thing for the screen to show. The Engine records beats; `Match` plays them back. |
| `Match.java` | Turns beats into animation: walking, rides, pianos, bombs, UFOs, floods, rewinds. Waits for your input between them. |
| `Fx.java` | Particles (smoke, sparks, fire, water, popcorn, foam, confetti, socks), props (piano, bomb, UFO, raccoons, laundry pile) and camera shake. |
| `Tower.java` | Builds the tower, one instance per tile (so bombs can remove one), labels, mailboxes, shafts, chutes, skyline, tokens and lighting states. |
| `Hud.java` | Setup, in-game HUD, card hand, card panel and targeting, Spare Key prompt, reveals, status line, floating text, screen effects, and which screen is showing. |
| `Menus.java` | Title screen, How to Play, Settings and the pause menu. |
| `Audio.java` | Music, sound effects and phone vibration. |
| `Settings.java` | Saved player settings. |
| `Seq.java` | Tiny animation queue. |
| `Ui.java` | Fonts and drawables generated at startup, sized for screen density. |
| `OrbitCamera.java` | One-finger orbit, pinch zoom, follows the active player or the current effect. |

## Running it

Requires JDK 17+. Open the folder in Android Studio (or IntelliJ with the Android plugin) and let Gradle sync. The Android SDK it builds against is API 36.

**Desktop (fastest to iterate):**

```
./gradlew lwjgl3:run
```

Keys: `1` = stairs, `2` = hustle, `Esc` = the phone's Back button, mouse wheel = zoom.

To test a card's animation, deal yourself up to three cards at the start of a game (desktop only):

```
./gradlew lwjgl3:run -Dcards=PIANO_DELIVERY,CHERRY_BOMB,ALIEN_ABDUCTION
```

Use the names from `Card.java`.

**On the S23 over USB:**

1. On the phone: Settings → About phone → Software information → tap **Build number** 7 times.
2. Settings → Developer options → turn on **USB debugging**.
3. Plug in, accept the prompt on the phone, then run:

```
./gradlew android:installDebug
```

Or press Run in Android Studio with the phone selected.

**Without a cable:** copy `android-debug.apk` to the phone, tap it in My Files, and allow your file app to install unknown apps when asked.

On the phone, Back closes an open card panel, pauses a running game, and steps back through the menus. It only exits from the title screen.

If the phone says "App not installed" when updating, the APK was signed by a different computer's debug key. Uninstall the old version first.

## Changing the board

Edit `ELEVATORS` and `CHUTES` in `Board.java`. Keep each pair a multiple of 10 apart, since the elevator shafts are straight vertical columns, and don't let one jump's end square be another jump's start. The 3D model rebuilds from those tables automatically.
